# Spam Email Detection using ML

A web application to detect spam emails using Machine Learning (TF-IDF + Naive Bayes) and Flask.

### 🚀 Live Demo Link
Will be added after deployment

### 🛠️ Technologies Used
- Python
- Flask
- Scikit-learn
- HTML / CSS

### 📁 Project Structure
- app.py - Main Flask app
- spam_model.pkl - Trained ML model
- templates/index.html - Frontend

### ▶️ How to Run
1. pip install flask scikit-learn
2. python app.py
